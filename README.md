- Built a secure Django / DRF platform with role-based dashboards for vendors and consumers to manage products, warranties, insurance, and invoices.
- Developed RESTful CRUD APIs across Admin, Vendor, and Consumer modules, including a vendor directory, invoice upload, and category-based search.

### Domain-Fine-Tuned Legal Document Summarizer
- Built an AI-powered legal document summarization platform integrating **LLaMA 2, BERT, and T5** via Hugging Face Transformers to generate executive-level summaries, obligations, and clause references.
- Developed RESTful APIs for document upload, summarization, export, and status tracking (PDF & DOCX support).
- Solved a model token-limit problem by chunking documents into 512–1024 token segments and combining chunk-wise summaries.
- Applied parameter-efficient fine-tuning (PEFT) and prompt engineering to adapt models to legal-domain text.
- Validated output quality using ROUGE-metric evaluation across 10+ documents.

**Tech Stack:** `FastAPI` `Hugging Face Transformers` `LLaMA 2` `BERT` `T5` `PEFT` `SQLAlchemy` `PostgreSQL` `PDFMiner` `ROUGE`
